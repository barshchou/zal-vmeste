# Зал вместе

Мобильный статический сайт с двумя 12-недельными полнотелыми программами тренировок. Работает без сборки, базы данных и внешних библиотек.

## Что внутри

- отдельные планы для него и для неё;
- тренировки A/B, фазы на 12 недель и правила прогрессии;
- подробная техника всех упражнений;
- дневник подходов и выполненных упражнений;
- таймер отдыха на 60, 90 и 120 секунд;
- советы по питанию, кардио, позднему залу и восстановлению;
- адаптация под телефон и компьютер.

Дневник хранится в `localStorage` браузера. Записи не синхронизируются между телефоном и компьютером и могут пропасть при очистке данных сайта.

## Открыть локально

Можно просто открыть `index.html` двойным щелчком. Для корректной проверки через локальный сервер:

```powershell
cd C:\Users\Slava\zal-vmeste
python -m http.server 8000
```

Затем открыть <http://localhost:8000>.

## Опубликовать на GitHub Pages

1. Создать на GitHub пустой репозиторий, например `zal-vmeste`.
2. В папке проекта выполнить:

```powershell
git add .
git commit -m "Create gym training guides"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/zal-vmeste.git
git push -u origin main
```

3. На GitHub открыть **Settings → Pages**.
4. В **Build and deployment** выбрать **Deploy from a branch**.
5. Выбрать ветку `main`, папку `/ (root)` и нажать **Save**.
6. Через несколько минут сайт будет доступен по адресу:

```text
https://ВАШ-ЛОГИН.github.io/zal-vmeste/
```
